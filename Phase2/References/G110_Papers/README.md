# G110 Papers

Every paper used in the project, organised the same way as in the presentation and the report.

| Folder | Content |
|---|---|
| [`PPT_15_Papers`](PPT_15_Papers) | the 15 papers cited in the presentation — file numbers = reference numbers [1]–[15] |
| [`Report_20_Papers`](Report_20_Papers) | the 20 papers cited in the report — file numbers = reference numbers [1]–[20]; folders follow the groups of Table 1 in the report |

All papers are IEEE publications (IEEE journals, IEEE conferences or IEEE/CVF conferences).
Each subfolder has a README with clickable links, and one `.url` shortcut per paper that opens the paper when the
repository is downloaded on Windows.

The full-text PDFs are not stored here because they are copyrighted by their publishers. Every link opens the
official page: open-access papers (IEEE Access, CVF Open Access) can be read directly, and the others can be
downloaded from IEEE Xplore through an institutional login.

A single list of all papers with authors and venues is in [`../Literature_Survey_Papers.md`](../Literature_Survey_Papers.md).
